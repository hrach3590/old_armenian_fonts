# old_armenian_fonts
# Hayfonts ArmSCII to Unicode Archive

Այստեղ հավաքված են հին հայկական հանրաճանաչ տառատեսակները, որոնք փոխակերպվել են ժամանակակից Յունիկոդ (Unicode) ձևաչափի:

It contains popular ancient Armenian fonts that have been converted to the modern Unicode format.

## 📥 Ինչպես ներբեռնել / How to Download
Ամբողջական փաթեթը ներբեռնելու համար սեղմեք կանաչ **Code** կոճակը և ընտրեք **Download ZIP**:
To download the entire collection, click the green **Code** button and select **Download ZIP**.
